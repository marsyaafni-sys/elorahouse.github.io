# ELORA HOUSE — Brandification Website

Static responsive prototype based on SRS v0.4.

## Pages
- Home
- About Us
- Catalogue
- Product Detail
- Wishlist
- Cart
- Checkout
- Dummy Login

## Run
Open `index.html` directly in a browser, or serve the folder with any simple local web server.

## Notes
- No database/backend is required.
- Wishlist and cart use browser localStorage.
- Login and checkout are dummy/prototype flows.
- Product and fashion images currently use remote Unsplash URLs as placeholders; replace them with the final ELORA HOUSE assets when available.
- Typography: Playfair Display for editorial headings + DM Sans for UI/body.
